# Mr. M Technology — Block Lab

A standalone, browser-based block-coding activity for Grade 5. Students practice movement sequences, run/step their code, and debug programs on a coordinate grid.

## Features
- Six progressive missions with an intentionally broken starter program for the debugging mission.
- Block editing, Run, Step, Reset, hints, and mission progress.
- **Copy Screenshot** and **Download PNG** evidence for teacher-assigned Google Slides submissions.
- Automatic progress saving in browser `localStorage` for up to 30 days after the last save, evaluated on the next visit; **Erase saved progress** for shared computers.
- No student accounts, names, passwords, access codes, application backend or analytics script.

## Getting started
Open [Block Lab](https://gabect.github.io/mr-m-block-lab/) or download the source and open `index.html` locally. Browser security restrictions may prevent copying images from a local file; use the hosted site or **Download PNG**.

## Student workflow
Choose a mission → arrange or modify blocks → Run / Step → debug as needed → Copy Screenshot or Download PNG → add the evidence to the teacher-assigned Google Slides presentation. Screenshots are **not** automatically submitted by Block Lab.

## Data and classroom use
Read [Privacy & Data Notice](PRIVACY.md) and [Educational Use Notice](EDUCATIONAL_NOTICE.md). Progress belongs to a browser profile, not an individual student. If devices are shared, erase progress between users. Website hosting may process normal request metadata independently of Block Lab.

## Project structure
- `index.html`: interface
- `styles.css`: styling
- `app.js`: missions, simulation, screenshots and local save
