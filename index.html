Teacher notes

Visit 1: Sequence basic movement blocks. Visit 2: Plan and test longer paths. Visit 3: A broken algorithm starts with four preloaded blocks. Run it, identify the obstacle collision at step 2, and edit the existing blocks using Change to reach C2. Students may use physical command cards before entering blocks.
