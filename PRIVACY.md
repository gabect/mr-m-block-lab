# Block Lab — Privacy & Data Notice
**Last updated:** October 27, 2026

Block Lab is a classroom coding activity that does not require an account, student name, password, email address, or access code.

## What Block Lab saves
The application saves the current mission, blocks placed in each mission, and which missions have been completed, using browser **localStorage** on the device. It does not request or store student names or other identifying information in the application. Progress is not synchronized across devices or browser profiles.

## How long is it kept?
The saved state contains a timestamp and is treated as expired **30 days after the last save**, when Block Lab is next opened. It is not a server-side scheduled deletion. Browser settings, private browsing, browser-data clearing, or school device management may remove it earlier. The **Erase saved progress** button clears saved progress from that browser.

## Screenshots and Third-Party Services
The screenshot buttons create an image of the mission, code, grid, and result on the student's device. **Copy Screenshot** uses the clipboard when the browser permits it; **Download PNG** saves a file. Block Lab itself does not upload, share, or submit these images to any external website, service, or application. If a user chooses to paste, upload, share, or submit an image through a third-party website, service, or app, that third party's privacy practices and terms, along with any applicable school or organizational policies, govern how the image is handled. Users should avoid including personal information in screenshots and use only teacher- or school-approved services when submitting classwork.

## Network and hosting
This version is a static HTML/CSS/JavaScript application hosted on GitHub Pages. The application does not contain an analytics tracker or an application database, but **GitHub Pages and network providers may process normal web-request metadata (such as IP addresses) under their own policies**. This notice does not claim that visiting the website produces no server logs. See [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Shared computers
Anyone opening Block Lab in the same browser profile may see the local progress left there. Students should use **Erase saved progress** after use on a shared classroom device, as instructed by their teacher.

## Contact / school use
For questions about classroom assignments, data handling, or the school's policies, contact your teacher or school administration. Do not type personal information into program blocks or screenshots.

This notice describes Block Lab's currently implemented behavior; it is not a claim of COPPA, FERPA, or other regulatory certification.
